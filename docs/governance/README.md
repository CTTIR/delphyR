# Governance material

The software provides functions that an organisation needs in order to decide
and to document; it does not decide for it. Nothing here is legal advice or a
statement of compliance.

- [Retention and removal](retention.md): what is stored, how to see its age,
  what the software removes by itself and what it never removes.
- [Processing record template](processing-record-template.md): a description
  of the processing with the fields the organisation fills in.

Fields marked *to be decided* are deliberately empty. A value that was used in
development is not a default for real use.
